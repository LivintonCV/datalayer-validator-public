# Glossary

- **Event**: A named analytics interaction (e.g., `page_view`, `add_to_cart`).
- **Field path**: Dot notation path to a value (e.g., `page.type`).
- **Rule**: A validation constraint (required field, allowed set, regex).
- **Finding**: A report item generated when a rule fails (or for info).
- **Severity**: `error`, `warning`, or `info`.
- **Evidence**: Metadata supporting a finding (source, timestamp, URL).
